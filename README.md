# Проект «Автомастер» — посадочная под холодную рассылку по СТО

## Цель
Лендинг + УТП + тестовый агент для владельцев автомастерских (мужчины, города-миллионники).
Паттерн: GitHub Pages → iFrame в Tilda (без субдоменов), как остальные лендинги.

## Аудитория
Владельцы СТО, шиномонтажей, автомастерских. Тон — строго «вы». Язык — прямой, без «нейро-зауми».

## Файлы
- `utp-avtomaster.md` — текст холодной рассылки (адаптация бьюти-УТП под СТО)
- `index.html` — лендинг (тёмная тема + оранжевый, каркас rusprom-landing)
- `agent-prompt.md` — системный промпт агента-приёмщика СТО для NoYa (в файл; слот в кабинете освободят позже)
- `../knowledge/company-profile.md` — общий профиль фирмы (каналы + интеграции), источник для всех лендингов

## Цены (тариф СТАРТ — одного агента достаточно, утв. владельцем; прайс от 01.02.2026)
- Тариф СТАРТ: 19 900 ₽/мес (вкл. 5 000 ₽ токенов — подтверждено владельцем)
- Лимит: 1 500 обращений/мес; превышение — 7 000 ₽ за каждые 1 500
- Интеграция (CRM/YCLIENTS/календарь): 11 000 ₽ разово
- Вход: первый месяц + интеграция = 30 900 ₽
- 6 месяцев разом: 107 460 ₽ вместо 119 400 ₽ (−10%)
- Входной аудит: 4 500 ₽ (как экспресс-аудит в линейке)
